Problem / Solution

Cybersecurity education is dry and syntax-heavy. By mapping secure memory safety to sterile cooking preparation, and SQL injections to recipe contamination, students grasp defensive patterns intuitively.

Business Model

Usage-based API and educational classroom tier. Free self-hosted proof-of-concept; charge for automated team grading and compliance certifications.

1-Week MVP Features

  • WebContainer in-browser Linux sandbox
  • 5 interactive cooking-recipe terminal challenges
  • Live memory sanitizer visualizer
  • Instant proof-of-work certificate export

Build Profile

Beginner difficulty, scoped for weekend build. Zero backend dependencies required for v1. Stack: React, Vite, WebContainers.
